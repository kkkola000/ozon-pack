Ключи Seller API

Личный кабинет Ozon → Настройки → Seller API → «Сгенерировать ключ». Ключи сохраняются в панели и применяются сразу, перезапуск не нужен.

Печать стикеров

По умолчанию печатается файл, который отдал Ozon, без изменений. В Chrome и Edge он уходит на принтер сам; в Safari открывается во вкладке, потому что печатать PDF из скрытого окна Safari не умеет — выходит пустой лист. Режим «Картинкой» печатает изображение стикера: он подходит, когда нужна автоматическая печать в Safari, но печатается уже не сам файл Ozon.

Принтер этикеток

Печать без окна печати: панель готовит команды принтера, а маленькая программа на складе (агент) забирает их и отдаёт принтеру по сети. Сервер в интернете не может достучаться до адреса 192.168.х.х напрямую, поэтому нужен агент — но открывать порты наружу не требуется.

Агент печати

Запустите на любом компьютере склада — он должен видеть принтер по сети. Нужен только Python, устанавливать ничего не надо. Скачать: print-agent.py

Адрес принтера агент возьмёт из этих настроек — менять его на складском компьютере не нужно. Ключ никому не передавайте: он даёт доступ к очереди печати.

Какие возвраты загружать

Сборщик должен видеть только то, что реально может получить. Панель забирает из Ozon возвраты в отмеченных статусах, остальные не сохраняет и не показывает.
