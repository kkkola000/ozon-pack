# Страница контактов магазина

`contacts/index.html` — самостоятельная страница (один файл, без библиотек и интернета).
Открывается двойным кликом или кладётся на любой хостинг / в GitHub Pages.
Удобно давать по QR-коду во вкладыше к заказу.

## Что заменить

Все места помечены в коде комментарием `ЗАГЛУШКА`.

1. **Ссылки** — у шести карточек стоит `href="#"`. Подставьте свои адреса:
   - Чат на Ozon
   - Чат на Яндекс Маркете
   - Наши контакты на сайте
   - Заявка на гарантийное обслуживание
   - ВК Видео
   - Rutube
2. **Логотип** — блок `<div class="logo">📦</div>` в шапке.
   Замените на картинку: `<img class="logo" src="logo.png" alt="Название магазина">`
   (файл положите рядом с `index.html`, квадратный, от 200×200).
3. **Название, режим работы, реквизиты** — заголовок `<h1>`, строка под ним и подвал.
4. **Иконка вкладки** — `<link rel="icon" ...>` в `<head>`.
5. **Подписи под названиями ссылок** — при желании поправьте текст в `<span>` внутри `.txt`.

## Мобильные устройства

Ширина контента ограничена 560 px и центрируется; на телефоне карточки занимают всю
ширину, высота нажатия не меньше 64 px. Отдельные правила для экранов уже 380 px.
Тёмная тема подхватывается автоматически из настроек телефона
(`prefers-color-scheme`), отдельного переключателя нет.
